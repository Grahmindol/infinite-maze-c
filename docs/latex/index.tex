\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{Features 🚀}{Features 🚀}}\label{index_autotoc_md3}
This project implements an {\bfseries{infinite maze generator}} ♾️.

The maze is {\bfseries{perfect}}:\+ ~\newline
 for {\bfseries{any two points}} in the maze, there exists {\bfseries{one and only one path}} connecting them 🧵.\hypertarget{index_autotoc_md4}{}\doxysubsection{\texorpdfstring{Key properties}{Key properties}}\label{index_autotoc_md4}

\begin{DoxyItemize}
\item 🌐 Infinite, procedurally generated maze ~\newline

\item 🛤️ {\bfseries{Unique path}} between any two positions ~\newline

\item 📏 The connecting path is always {\bfseries{finite}}, even though the maze itself is infinite ~\newline

\item 🌲 Structurally equivalent to an infinite spanning tree ~\newline

\end{DoxyItemize}

This guarantees {\bfseries{no loops}}, {\bfseries{no ambiguity}}, and deterministic navigation throughout the maze.

Stream the unique shortest path between two world coordinates.

Computes and streams the deterministic shortest path between two world-\/space coordinates inside the given infinite maze.

{\bfseries{Parameters}}
\begin{DoxyItemize}
\item {\ttfamily maze\+\_\+p} — Pointer to the root maze instance.
\item {\ttfamily fwx} Starting world X coordinate.
\item {\ttfamily fwy} Starting world Y coordinate.
\item {\ttfamily twx} Target world X coordinate.
\item {\ttfamily twy} Target world Y coordinate.
\item {\ttfamily walker} Callback invoked for each world coordinate along the path.
\item {\ttfamily user\+\_\+data} User-\/defined pointer passed unchanged to the callback.
\end{DoxyItemize}

{\bfseries{Complexity}}
\begin{DoxyItemize}
\item {\bfseries{O(\+L) = O(exp(d))}} where L is the number of world cells along the path. and d is the distance of the farthest point to the origine.
\end{DoxyItemize}

{\bfseries{Notes}}
\begin{DoxyItemize}
\item The path is streamed in traversal order from start to target.
\item Concurrent calls must operate on distinct maze instances.
\end{DoxyItemize}
